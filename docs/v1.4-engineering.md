# 1.4 识别与交互改造

声幕1.4围绕“选择声音、开始字幕、持续阅读、知道如何恢复”调整主窗口，并增加CPU多语和原生流式识别路径。原有音源、独立字幕显示、翻译、外观和托盘功能保留。

## 识别选择

- 新安装默认SenseVoice INT8：中、粤、英、日、韩，CPU两线程；Silero VAD分段，起声前保留300ms，500ms节奏预览。它是非流式模型的分段字幕方案。
- Whisper保持现有词时间滚动合并，新增Turbo、英语专用tiny.en/base.en和distil-large-v3；CPU INT8、GPU FP16及INT8_FLOAT16分别选择。已有模型设置不自动替换。
- Zipformer Transducer及CTC small/medium复用sherpa缓存，只送新增音频，使用partial/final。小CTC降低了测试进程内存，但短句有错漏，因此标为实验；自动模式不提供语言检测，翻译时需指定源语言。

模型支持范围在准备前校验。ONNX文件按固定revision、尺寸和SHA256准备，只取目标量化文件及tokens；Whisper复用已有缓存。模型许可与运行时代码许可分开，见第三方说明。

## 运行状态

四页为实时字幕、字幕外观、高级设置和开始使用/排查。高级解码预设移到高级页；主页面显示当前音源、输入电平、实际设备、最近识别处理和音频积压。指标不是完整声学延迟，不虚构缺少的词时间。

停止先拒绝新音频和旧回调，待模型与工作线程释放才恢复开始。队列按采样数限制15秒，过载后记录音频缺口并重置上下文。只改翻译设置时保留已经识别的final；自动检测语言同步更新，避免旧语言状态阻止新翻译。

主窗提供最近64段复制和TXT导出；找回字幕窗将其移到当前屏幕下部并保留样式。新安装默认本地翻译，在线选项明确说明MyMemory接收识别文本。

## 验证与交付

本轮完成197项测试，包括后端原生接口mock、文本段落、配置交错、停止释放、过载和代理分支。使用同一公开音频比较CPU/GPU、量化精度、线程和流式组合，并做五语自动识别冒烟。短样本用于选择与暴露问题，不作为普遍准确率排名。

真实Windows系统播放回环经SenseVoice到实际浮窗已出现测试字幕。安装版1.4.0再次加载本机模型、采集系统声音并显示字幕；Ctrl+Enter停止后恢复开始，Ctrl+Q退出。构建记录绑定实际源码HEAD与modified状态，当前为本地开发包。

构建/打包按项目AGENTS和发布流程执行；本机开发过程可用ASR_TASK_ROOT把构建临时文件定向到对话目录。模型留在原应用目录，Apps只指向当前安装版。完整研究、需求、交互、架构、实测结果和安装回执保存在本次对话工作区，由本机Apps索引定位。

Fun-ASR-Nano、Nemotron、Qwen等更广选型已纳入研究；它们没有在1.4中冒充已接入后端。后续先补充真实用途的固定参考语料，再决定新运行时与默认方案。


## 1.4.1 阅读与设置体验

主窗压缩标题和运行卡，常用音源、语言、模型、设备、翻译与最近字幕在默认窗口首屏可达。运行详情默认收起，故障时展开诊断信息；Tab 自动滚入当前控件，PageUp/PageDown 可滚动设置页。模型筛选只控制列表，保留正在使用的模型键及设置。配置窗口及其模型管理窗口获得焦点时，浮窗临时让出置顶，离开后恢复用户的置顶偏好。

Whisper 新出现的句末标点先进入即时草稿，连续窗口确认后才用于不可逆分段，避免一次错误句号把后续修订锁成碎片。跨旧确认边界的重复单字按词时间检查，真实重复发音仍保留。它改善分段稳定性，不保证修正专名和口语错字。

## 显式开启有限时长诊断

普通启动不保存录音或识别全文。需要验证语音到字幕的时间时，在任务工作区指定独立目录：

```text
AudioSubtitleOverlay.exe --trace-dir E:\AI\<conversation>\evidence\live --trace-seconds 120 --trace-audio --trace-text
python tools/trace_live.py reference <run-directory> --output <run-directory>/reference.json
python tools/trace_live.py analyze <run-directory> --reference <run-directory>/reference.json --output <run-directory>/timing-report.json --csv <run-directory>/phrase-timing.csv
```

音频、全文开关分别选择；默认120秒、最多600秒，默认16 MiB且队列有界，达到限制自动结束，写失败不阻塞识别。结束记录包含丢事件、待写入数和错误；证据不完整时不能报告完整测量。参考工具只使用本地已缓存模型，不下载、不上传。

进程回环保留WASAPI QPC包时钟；系统回环只有回调估算，报告须区分。每次识别、源文字版本、实际可见行提交按会话/序号关联，只给实际进入视口的文字计时，历史滚动不充当首次显示。绘制时间是向Windows提交图像后的时点，不能当作显示器扫描时间。独立自动参考的词边界仍是估计，匹配覆盖率不等于识别准确率；准确率需另用人工校对的同一段参考文本评估。

本次可复用方法保存在项目工具和此维护说明。它依赖声幕的事件格式和运行时，继续由现有性能、功能验证及工作区Skill协调，无需新增同义全局Skill。真实环境比较应固定音频、模型、参数和计时端点，分别记录即时预览、确认文本和可见文字。
