# 2.2.0 控件、自定义参数与鼠标穿透

本页说明2.2.0的控件与输入行为、参数范围和维护方法。安装包身份及同包运行结果以对应交付回执为准。

## 完整字段的悬停

音源、语言、模型等分类选择器仍只接受列表中的选项。鼠标进入文字、空白、边框或箭头时，整个字段显示同一悬停状态；在字段内移动不切回默认。焦点外环与悬停、展开状态同时可见；禁用状态优先。

## 在推荐值之外输入参数

“高级设置”中的数值正文可以直接编辑，右侧箭头列出推荐值。推荐值提供常用起点，自定义值按下表校验。

| 参数 | 允许值 | 使用它的引擎 |
|---|---|---|
| 搜索范围 | 整数1–16 | Whisper |
| 最大音频窗口 | 整数1–30秒 | Whisper |
| 更新间隔 | 0.1–5秒 | Whisper；CPU实际不低于0.5秒，CUDA不低于0.1秒 |
| 重复惩罚 | 0.1–5 | Whisper |
| 禁止重复词组长度 | 整数0–64；0关闭 | Whisper |
| 无语音概率阈值 | 0–1 | Whisper |
| 分段静音时长 | 整数1–5000毫秒 | Whisper、SenseVoice |
| 解码温度序列 | 1–8项，每项0–1；按输入顺序使用 | Whisper |

这些边界是本产品的输入范围。Whisper的计算成本会随窗口、搜索范围和温度重试数量增加；很短的静音时长容易切碎句子。SenseVoice只有分段静音时长使用这里的值，Zipformer使用自身的原生分段。未使用的参数会保留为相应引擎偏好，切换回使用它的引擎后应用。

键入期间只编辑草稿，识别继续使用最近一次已提交值。Enter或真正离开字段时应用有效输入，Esc还原。箭头弹层属于同一字段：取消或第一次Esc只关闭弹层并保留草稿，再按Esc才还原；选择推荐项直接提交该推荐值一次。

输入采用普通十进制，整数项不接受小数。空白、单独的正负号、尚未写完的小数、非数值、NaN、Inf、科学计数和越界值在提交时给出可读提示；保留草稿及已提交值，不抢回焦点。单个数值最多64字符，温度编辑文本最多512字符，每项最多64字符；超长值明确拒绝。温度可用英文逗号、中文逗号或顿号分隔，数值等价的重复项会被拒绝，不会自动截断、去重或调整顺序。

有效自定义值随原有设置保存，重新启动后保留。配置文件中合法的有限JSON数值按其类型读回；未改动的已保存值即使普通十进制显示很长，也不会在失焦时误套新输入的长度限制。分类选项、模型和设备身份继续由原列表选择。

## 让鼠标操作下方窗口

在“字幕外观”的“字幕窗鼠标操作”卡打开“让鼠标穿过字幕窗”。开启后，文字、空白、边缘和调整大小区域都由下方窗口接收鼠标操作；字幕继续更新。穿透期间无法从浮窗本身拖动、右键或回看历史。

恢复鼠标操作使用任一外部入口：

- 回到主窗“字幕外观”，点击“恢复鼠标操作”。
- 右键Windows通知区域的声幕托盘图标，选择“恢复鼠标操作”。

没有托盘时，主窗保留任务栏入口。启动应用保存值之前，先备好回调和外部恢复入口；应用失败时显示主窗。开关显示原生实际读回，只有确认生效后才保存新偏好。状态未知时显示短横和“状态未确认”，保留原保存偏好，恢复按钮仍可请求关闭穿透；已知失败按实际开关值显示。

## 动效和维护验证

命中、编辑、校验、弹层和穿透切换即时生效。已有历史滚动保留当前速度和物理收敛；窗口隐藏时停止排帧，关闭动态或系统减少动态时立即落到目标并清零速度。

参数规则集中在`recognition_parameters.py`，Settings、主窗和Whisper解码共同使用。草稿事件与外部恢复集成分别由`tests/test_parameter_editing.py`、`tests/test_mouse_passthrough_controls.py`和`tests/test_tray_control.py`覆盖；原生样式及滚动生命周期另有对应测试。

无窗口测试核对类型、边界、真实保存重载、解码入参、弹层提交和迟到回调。Windows用途验证另检查深浅主题、文字放大、真实指针四区域、Enter/Esc/Tab、持续字幕期间草稿保持，以及最终包从主窗/托盘恢复。穿透必须核对下方自有窗口收到左/右/双击、拖动、滚轮和边缘输入；窗口样式位或模拟回调不能替代这项结果。保留用户当前模型、设备、音源、字号、颜色和透明度，不套用旧测试配置。

维护与复验还需核对以下条件：

- 标签请求宽度不等于grid实际分配槽宽；自动换行按分配槽扣除间距计算。整行矩形位于viewport内，也不能证明文字完整可读。深浅主题、放大文字和错误/未知等关键状态都检查实际图像中的全文及读序。
- 隔离验收保留当时正式模型、设备和音源选择，复用已安装的模型缓存与CUDA依赖。先核对隔离环境是否具备这些条件，再判断产品调用链；固定条件发生变化时保留原轮记录并重新验收。
- ASR发布原文和UI呈现原文分别记录版本与时间。译文帧按绘制时UI已呈现的源版本核对，后台刚发布但UI尚未消费的版本不提前算入当前画面。MT输入仍与原始源快照精确配对；显示规范化只按目标包实际源码处理，并绑定该包的BUILD_INFO。
- 鼠标路由按原生消息到达、Tk绑定回调、控件状态和下方窗口结果逐步核对。缺少Tk回调不能单独证明Windows未送达消息；样式位也不能代替下方窗口收到输入。普通拖动沿用Tk已有按钮捕获，切穿透、隐藏和关闭时核对自有捕获已释放，异常路径同样检查。
- UI工具沿用产品的默认DPI创建条件，分别记录实际DPI awareness、窗口DPI与Tk文字倍率。逻辑/物理坐标通过目标HWND转换；临时测量context退出后恢复。焦点滚动由真实FocusIn触发，不在focus_set之后再次手动调用同一handler；重复回调健壮性另测，不能混入正常操作链。
