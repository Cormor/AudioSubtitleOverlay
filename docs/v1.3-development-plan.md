# 声幕 v1.3：交互与发布计划

## 目标

保持原文连续、尽快显示，翻译不阻塞原文；常用操作无需在长设置页中寻找。用户配置、模型和缓存继续使用原位置。

## 名称与视觉

- 名称：**声幕**；副标题：**实时字幕与翻译**。
- 图标：声波与字幕行放在同一个对话框中，深蓝底、青色线条；16 px 托盘尺寸仍能辨认轮廓。
- 设置界面：深蓝标题区、浅色内容卡片、青蓝操作强调色；正文使用系统中文字体，不以低对比灰字承载关键状态。
- 原文、译文分别设置字号和颜色，提供高对比外观预设。

## 交互布局

- 顶部固定操作栏：开始、停止、显示字幕、模型管理、收进托盘。
- **识别**：音频来源、语言、模型和设备、翻译、最近结果。
- **字幕外观**：外观预设、颜色、字号、透明度、置顶与自动高度。
- **高级**：解码参数、启动行为与更多模型参数；参数预设与模型分别设置；五档预设不换模型，手调后显示为自定义。
- 设置自动保存；关闭或最小化设置窗后收进托盘，不停止字幕。
- 托盘图标恢复设置，并可显示／隐藏字幕、开始／停止识别、退出。
- 托盘初始化失败时保留任务栏窗口，不把应用藏到无法恢复的位置。
- 有过译文后，即使原文停更，译文区继续显示。

## 性能工作

1. 分别记录输入终点到上屏、推理、排队、结果到上屏、窗口末词到上屏估计；不混淆最后一个词与整句完成时间。
2. 仅在已确认的停顿处分界，不在连续句子中按确认字符裁窗；保留最大窗口作为上限，并验证不会重复或漏掉句尾。
3. 不在 UI 主线程下载、翻译或执行模型推理；实时结果不等待历史字幕逐行播放。
4. 使用同一音频和同一模型做前后对照，再验证合并结果、重复文本、停顿、配置切换和恢复。
