## 缺口及修正

前轮组件图库与运行截图不能替代实现前完整页面设计；只读下拉仅改原生列表颜色，行高、内距、当前值与键盘活动没有独立受控设计。验收只覆盖局部视觉和关闭态，漏掉长设备列表的展开层。此次先建立可编辑SVG、导出PNG、manifest与渲染脚本，再审查图稿、实现与实际安装包。

图组覆盖五页深浅主题、模型管理、音源展开、长列表和长文本、后部选中、短工作区上翻、推荐与当前设置、状态板与滚动续页。选项卡另补鼠标选择、键盘焦点、焦点移入正文与窗口重新激活组合图。设计图中的示例设备和字幕为公开测试文案，不代表用户现场状态。

下拉源于公司语义令牌和项目组件表，保留ttk只读字段的值、动态postcommand、当前索引与ComboboxSelected事件语义。仅替换展开呈现，不修改可编辑输入行为。行高max(36,字体行高+16)Tk逻辑像素，外框8px圆角，内距6px，字段与弹层4px；统一预留勾列，长值按原字号换行，列表最多8个基础行并受真实工作区约束。选中为弱金底、勾和竖条；悬停灰底；键盘活动独立细框。推荐仍为实际选项文字，不冒充当前设置或实际设备。

当前页使用同一位置的底线；取消页签全轮廓，键盘焦点按有效图组增强原底线，不新增第二处包围强调。鼠标操作和窗口激活不切换为键盘模式，焦点进入内容后恢复普通底线。

## 实现与异常

choice_popup.py负责临时展开层、工作区定位、原生圆角区域、鼠标/键盘输入与关闭清理；theme.py接入共用选择器。main.py的焦点显露在Toplevel边界停止，避免弹层焦点滚动背景页。关闭时独立处理原生focus/grab查询的KeyError，销毁窗口并释放自己拥有的资源，不覆盖较新的模态抓取。

Windows首次跨入窗口可只产生Enter事件；Tk官方实现[tkPointer.c](https://github.com/tcltk/tk/blob/core-8-6-branch/generic/tkPointer.c)的GenerateEnterLeave分支会更新lastPos以避免重复Motion。原来只绑定Motion会漏掉首次悬停，现同时处理Enter；最小真实指针对照与完整边界脚本分别复验，未引入轮询或改为全局抓取。
