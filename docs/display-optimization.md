# 字幕显示与阅读行为

## 实时阅读

- 原文在固定上区，译文在固定下区，字号分别设置，字形按字体上升线/基线定位，不按各字符串的字形顶部定位。每区显示最近完整行，新增一行才推进旧行。
- 原文区内部基线固定，译文长度改变不移动原文区。译文短暂为空不收起译文区；已有部分译文、原文继续增长时保留译文并标记“更新中”。
- 手动指定源语言时，仅按源语言与目标语言是否相同启用译文区，不因译文为空收起。自动检测时先保留译文区；原文持续更新且连续 5 秒没有译文输出才隐藏，译文输出恢复立即展开。检测出的中英文切换不重置这 5 秒计时。原文停止更新期间不因空闲时间收起。
- 实时阅读最多保留一个视口的待显示行，突发长结果直接靠近最新部分，旧内容仍可滚动回看，避免逐行播放积压历史造成长延迟。已显示行按“每行停留最低时间”整行推进，独立定时，不受识别刷新频率驱动；“回到最新字幕”可跳过积压。实时更新不做文字淡入或逐帧纵向追赶，避免尚未看清就变淡、滑走。历史回看仍保留滚轮缓动。

## 窗口尺寸与交互

- “自动收起空译文区”开启时，按上述语言和 5 秒规则收起译文区时自动缩短窗口，重新启用时恢复用户选定的双语高度；切换不覆盖保存的首选高度。不随字幕字数调整高度。
- 原文与译文最少各一整行，无论是否启用自动收起均可拖到一行。单语状态调整高度会换算成对应双语首选高度，反复收起、恢复不累积增高。
- 右下角手柄为 40 × 36 像素的独立非透明操作区，即使背景透明、文字透明度为零也能命中。正文预留底部操作区，不画在手柄下面。
- 右侧滚动条有 20 像素宽独立可点击区域，支持按住滑块拖动、点击轨道跳转、越界拖动与反向返回；拖动不移动窗口，松手到底部恢复实时阅读。滚轮向上进入成对历史阅读；“回到最新字幕”返回独立双语实时区。当前模式不会同时叠画历史固定区。
- 更改窗口尺寸后等待 Configure 再提交对应尺寸位图，不用旧尺寸位图覆盖刚调整的原生窗口。

## 换行与版本

- 拉丁文字优先按词边界换行；中文避免收尾标点孤立在行首、起始括号悬在行尾。
- 行账本增长从末行的真实起点续排，不重新消费已处理的换行或空白。
- 草稿停顿只补标点，确认分段由统一提交路径产生，不在高频候选上插入反复变化的硬换行。
- 重叠窗口前移时先提交过期候选，再按新的确认边界裁剪新窗口，防止同一音频前缀被两次追加。后续真实重复播放的相同话语依然保留。
- 原文只向后增长时保留已译部分并标记“更新中”；原文发生纠错时清除该版本的过时译文；迟到的旧译文不再挂到新版本。先到的同序号译文仍能在原文到达后挂接。
- 历史保留最近 64 段，序号映射和提前到达的翻译缓存有界，避免长时间运行的显示工作量无上限增长。历史淘汰后保留其余段落的换行缓存，不把剩余历史全部重新排版。

## 验证

测试覆盖换行字符范围、空白/换行续排、双语分区、译文迟到和增长、窄视口完整行边界、原文修订后译文归属、过期候选去重与真正重复话语、Unicode 重叠匹配等。
实际验证另检查 Windows 原生窗口尺寸、手柄命中、连续帧分区矩形、拖动放大、历史回看与当前本地音频的识别翻译。构建成功、进程存活与真实字幕显示分别记录，不能互相替代。

## 翻译开关与识别文字

- “启用翻译”可在运行中关闭。关闭后不再提交新的翻译任务，清空等待队列，丢弃已经在执行的旧调用结果；原文识别继续。源语言与目标语言相同时同样不调用翻译后端，自动模式按当前检测语言判断。
- 只切换翻译开关、翻译后端或目标语言不会重载识别模型、重连音频或清空原文。
- 识别适配层在滚动确认前净化字幕署名格式，支持跨词及缺少首字的形式，保留其余文字的时间范围。日志只记录净化数量，不写出原始识别内容。
- 上屏耗时日志标明实时阅读或历史回看；历史回看旧句的耗时不能当作实时识别延迟。
